# Branding actualizado

Usa estos archivos exactos:

- `frontend/public/assets/branding/brand-logo.png` → logo principal del header
- `frontend/public/assets/branding/favicon.png` → ícono de pestaña del navegador

## Importante
- `brand-logo.png` es para el encabezado principal.
- `favicon.png` es solo para la pestaña.
- Si falta `brand-logo.png`, se mostrará el fallback con las siglas HS.
